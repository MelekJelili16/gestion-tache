# Application Python de Gestion des Tâches

Application console développée en Python permettant de gérer une liste de tâches quotidiennes.

## Fonctionnalités
* **1 – Ajouter une tâche** : Saisie d'un titre avec vérification contre les entrées vides.
* **2 – Afficher les tâches** : Affichage numéroté de toutes les tâches enregistrées (ou message si la liste est vide).
* **3 – Rechercher une tâche** : Filtrage des tâches par mot-clé (insensible à la casse).
* **0 – Quitter** : Fermeture propre de l'application avec gestion des choix invalides.

## Étapes de développement réalisées
1. Création de la structure de base du menu et de la boucle principale (`while`).
2. Implémentation de l'ajout et de l'affichage des tâches via une liste Python.
3. Rédaction de la documentation initiale dans `README.md`.
4. Ajout de la fonction de recherche par mot-clé et amélioration de la gestion des erreurs.

## Méthode d'exécution dans VS Code
1. Ouvrir le dossier du projet dans **Visual Studio Code**.
2. Ouvrir le fichier `main.py`.
3. Cliquer sur le bouton **Run Python File** (icône triangle lecture en haut à droite de l'éditeur).
4. Interagir avec le menu directement dans le terminal intégré en bas de l'écran.
